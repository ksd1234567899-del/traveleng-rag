# 여행 영어 개인화 RAG 튜터

RAG(Retrieval-Augmented Generation)와 LLM을 활용해, 사용자별로 개인화된 영어 회화 학습이 실제로 가능한지를 검증한 프로토타입입니다.

텍스트 기반 1:1 롤플레잉 형태로, 공항·레스토랑·호텔 등 실제 여행 상황에서 AI 캐릭터와 대화하며 영어를 연습합니다. 단순히 문법을 고쳐주는 챗봇이 아니라, **사용자의 문법 실수와 표현 습관을 세션과 시나리오를 넘나들며 기억하고, 그 데이터로 대화 내용과 난이도를 자동 조정하는 것**이 핵심입니다.

## 왜 만들었나

기존 AI 회화 학습 앱들은 대화가 끝나면 기록이 초기화됩니다. 어제 틀린 표현을 오늘 또 틀려도 AI는 모릅니다. "AI 튜터가 나를 계속 기억하고, 시간이 지날수록 나에게 맞춰진다"는 경험을 RAG 기반 개인화로 실제 구현할 수 있는지 검증하고 싶었습니다.

## Features

- **다층 개인화**: 문법 실수는 빈도와 함께 저장해 재발 시 우선 교정, 표현 습관(단조로운 어휘 등)은 별도로 추적해 명시적으로 피드백, 교정률·표현 복잡도를 분석해 레벨을 자동 조정
- **몰입형 롤플레잉**: 5가지 여행 시나리오, 레벨에 맞는 난이도의 미션 자동 생성, 캐릭터와 교정 튜터를 분리해 몰입 유지
- **RAG 파이프라인**: 매 턴 메타데이터+벡터 검색을 결합해 개인화 컨텍스트 조합, 시나리오를 옮겨도 기록이 끊기지 않음
- **사전 진단 & 리포트**: 첫 접속 시 스몰토크로 초기 레벨 진단, 세션 종료 시 학습 리포트 자동 생성

## 배운 점

- **프롬프트만으로는 안 지켜지는 규칙이 있다.** 롤플레잉 캐릭터와 교정 튜터의 발화 순서를 프롬프트로 통제하려 했더니 계속 깨졌고, 코드로 강제하고 나서야 안정됐습니다.
- **단일 지표는 이상한 결과를 낳는다.** "실수 안 하면 레벨 상승"만으로는, 단조로운 문장만 쓰는 사람이 오히려 유리해지는 역설이 생겼습니다. 실수율과 표현 시도 정도를 함께 봐야 했습니다.
- **로그는 처음부터 구조화해야 한다.** 대화만 저장했더니, 나중에 "왜 이렇게 판단했는지" 근거가 안 남아있었습니다.
