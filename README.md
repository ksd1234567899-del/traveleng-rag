#여행 영어 개인화 RAG 튜터

##소개
RAG(Retrieval-Augmented Generation)와 LLM을 활용하여, 사용자별로 개인화된 영어 회화 학습이 실제로 가능한지를 검증하는 프로토타입입니다.
텍스트 기반 1:1 롤플레잉 형태로, 사용자가 공항·레스토랑·호텔 등 실제 여행 상황에서 AI 캐릭터와 대화하며 영어 표현을 연습합니다.
단순히 문법을 교정해주는 챗봇이 아니라, 사용자의 문법 실수와 표현 습관을 세션과 시나리오를 넘나들며 기억하고,
그 데이터를 기반으로 대화 내용과 난이도를 자동으로 조정하는 것이 이 프로젝트의 핵심입니다.

##문제의식
기존 AI 회화 학습 앱은 대화가 끝나면 기록이 초기화되어, 매번 처음 만난 사람처럼 반응합니다. 
이 프로젝트는 "AI 튜터가 나를 기억하고, 시간이 지날수록 나에게 맞춰진다"는 경험이 RAG 기반 개인화로 실제 구현 가능한지를 검증합니다.

##Tech Stack

###Backend (claude code로 개발)
Node.js / TypeScript
Express (API 서버)
Claude API (Anthropic) — 대화 생성 및 튜터링 로직
OpenAI Embeddings — 벡터 검색용 임베딩
SQLite (node:sqlite) — 학습자 메타데이터 저장
vectra — 경량 로컬 벡터 데이터베이스

###Frontend
React (Lovable로 개발)

###Infra
Railway — 서버 배포 및 영구 데이터 저장(Volume)
GitHub — 버전 관리

시스템 아키텍처
[사용자 입력]
     │
     ▼
[검색] SQLite 메타데이터 + vectra 벡터 검색
     │
     ▼
[판단] Claude API — 문법 오류 / 표현 습관 / 미션 관련성 독립 판정
     │
     ▼
[생성] 개인화 컨텍스트를 반영한 캐릭터 응답 + 튜터 피드백
     │
     ▼
[저장] 세션 종료 시 신규 패턴·레벨·미션 결과 갱신

Features
다층 개인화
문법 실수를 빈도와 함께 저장, 재발할수록 우선적으로 검색되고 교정 어조도 강해짐
문법적으로 틀리진 않았지만 반복되는 표현 습관(단조로운 어휘 등)을 별도로 추적해 명시적으로 피드백
세션별 교정률·표현 복잡도를 함께 분석해 레벨(A2/B1/B2)을 자동으로 조정

몰입형 롤플레잉
5가지 여행 시나리오(공항/레스토랑/호텔/택시/관광안내소)
레벨에 맞는 난이도로 매번 다른 미션 자동 생성
롤플레잉 캐릭터와 교정 튜터를 분리해, 교정이 몰입을 깨지 않도록 설계
상황이 자연스럽게 끝나면 AI가 스스로 세션 종료

RAG 기반 개인화 파이프라인
매 턴마다 메타데이터 필터링 + 벡터 검색을 결합해 그 순간에 맞는 개인화 컨텍스트 조합
시나리오를 옮겨 다녀도 학습자 기록이 끊기지 않고 이어짐

사전 진단 & 세션 리포트
첫 접속 시 스몰토크로 초기 레벨 진단
세션 종료 시 미션 달성 여부, 교정 내역, 다음 학습 포인트 자동 요약

##배운 점
프롬프트 지시만으로는 안 지켜지는 규칙이 있다. 롤플레잉 캐릭터와 교정 튜터의 발화 순서를 프롬프트로만 통제하려 했더니 계속 깨졌고, 결국 "이번 턴엔 튜터만 응답한다"를 코드 레벨에서 강제하고 나서야 안정됐습니다. AI에게 "하지 마라"고 말하는 것보다, 애초에 할 수 없는 구조를 만드는 게 훨씬 확실하다는 걸 배웠습니다.
단일 지표로 평가하면 이상한 결과가 나온다. 처음엔 "실수를 안 하면 레벨 상승"으로만 판단했는데, 이러면 짧고 단조로운 문장만 반복하는 사람이 오히려 유리해지는 역설이 생겼습니다. "실수율"과 "표현을 시도한 정도"를 함께 봐야, 도전하다가 틀린 사람과 아예 시도를 안 한 사람을 구분할 수 있었습니다.
로그를 처음부터 잘 설계해야 한다. 초반엔 대화 내용만 텍스트로 저장했는데, 나중에 "레벨이 왜 이렇게 바뀌었는지" 확인하려니 근거가 하나도 안 남아있었습니다. 판단 근거(수치, 사유)를 처음부터 구조화된 형태로 같이 저장했어야 했습니다.
작게 쪼개서 검증하는 게 결국 더 빠르다. 한 번에 다 만들려 하지 않고, 기능 하나씩 개발자 테스트로 확인하고 넘어간 덕분에, 버그가 나도 원인 추적이 훨씬 쉬웠습니다.

##향후 계획
실제 사용자 대상 알파 테스트(15명) 진행 및 정량적 성능 평가
개인화 유무에 따른 비교 실험으로 효과성 직접 검증
음성 인터페이스(STT/TTS) 확장 — 텍스트보다 스피킹 환경에서 개인화 효과가 더 크게 체감될 것으로 예상되나, 음성 인식 오차라는 변수를 통제해야 해서 이번 프로젝트 범위에서는 제외함
어휘 다양성, 문장 복잡도 등 정량 지표를 활용한 개인화 효과 측정 고도화
